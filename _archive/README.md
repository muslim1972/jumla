# أرشيف مشروع جملتي (`_archive`)

هذا المجلد مخصص لحفظ كافة الملفات التشخيصية، السكربتات المؤقتة، الترقيعات، ونصوص SQL التاريخية التي تم تنفيذها أو استخدامها سابقاً أثناء التطوير.

## البنية التنظيمية:
- `root_scripts/`: السكربتات البرمجية التي كانت متناثرة في جذر المشروع (فحوصات، حقن بيانات، ترقيع واجهات).
- `sql/`: ملفات وقواعد SQL المرجعية القديمة وسجلات المخطط التاريخية.
- `patches/`: أي ملفات تصحيح مؤقتة أو مخصصة مستقبلاً.

## القواعد الصارمة:
1. **يُمنع منعاً باتاً** إنشاء أي سكربت تشخيصي أو فحص مؤقت في جذر المشروع (`D:\jumla\`) أو في `src/`.
2. أي سكربت يُراد تشغيله لمرة واحدة أو لفحص محدد يُكتب حصراً داخل `_archive/`.
3. لا يتم استيراد أي ملف من `_archive` داخل كود التطبيق في `src/`.
