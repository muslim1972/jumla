## 2. الدرع المعماري ومحرك الإنفاذ الحتمي لإطار B.R.I.C.K (OPS-03)
- **دستور المشروع:** `AGENTS.md` في جذر `D:\jumla\`.
- **المصطلحات الرسمية الحصرية:** يُحظر استخدام لفظ «طابوق» أو مشتقاته نهائياً؛ وتُعتمد حصراً مصطلحات ورقة الباحث م. مسلم عقيل عبد الحسن العنزي: **«إطار عمل B.R.I.C.K»**، **«محرك الإنفاذ الحتمي (OPS-03)»**، و**«الأنوية المعمارية السيادية B.R.I.C.K (Kernels)»**.

### المسلمات والقواعد الحتمية الست للنظام (The 6 System Invariants - v3.0):
1. **مسلمة شمولية التغطية وانعدام الملفات غير المنسوبة (Closed-World Zero-Orphan Invariant):** كافة ملفات `src/` منسوبة 100% لأنوية B.R.I.C.K في `bricks/registry.json`.
2. **مسلمة الحيازة الأحادية المطلقة (Exclusive Single Ownership Invariant):** حظر الملكية المزدوجة لأي ملف أو كائن قاعدة بيانات بين نواتين.
3. **مسلمة مطابقة الحالة التشفيرية (Cryptographic State Invariant):** صيانة بصمات التجزئة التشفيرية (`bricks/fingerprints.json`) ومنع التعديلات الجانبية العشوائية.
4. **مسلمة التكافؤ التعاقدي بين القواعد والاختبارات (Contract-Test Mapping Invariant):** كل قاعدة عمل ملزمة تقابلها اختبارات برمجية تبرهن صحتها حاسوبياً.
5. **مسلمة الحظر السيادي للتعديل العابر وحصانة الأذونات (Sovereign Non-Bypass & Privilege Invariant):** حظر التعديل المباشر على جداول مملوكة لنواة أخرى دون عقد رسمي، واقتران الدوال السيادية بالأدوار المعتمدة واستيفاء سياسات RLS.
6. **مسلمة التأصيل الهيكلي القطعي والإلزام التنفيذي للدوال (Strict Schema Grounding & Execution-Proof Invariant):** حظر هلوسة أسماء الأعمدة النمطية (*Semantic Schema Priors*) دون إثبات وجودها الفعلي في كتالوج قاعدة البيانات، وإلزام الفحص التنفيذي الدخاني المحمي (*Smoke Invocation Gate*) لإحباط أخطاء الربط المتأخر (*Late-Binding*).

### مسار التحقق الإلزامي الثلاثي قبل النشر:
```powershell
# خطوة 0: محرك الإنفاذ الحتمي لإطار B.R.I.C.K
node scripts/verify-bricks.mjs

# خطوة 1: فحص الأنواع الصارم (معيار الصفر TS Errors)
npx tsc --noEmit

# خطوة 2: بناء الإنتاج وتحقق التوافقية
npm run build
```
